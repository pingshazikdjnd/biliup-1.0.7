# 2026-07-09

## biliup 项目架构梳理（通读全部核心文件）

这是一个**多平台直播录制+自动上传**工具（biliup，非 bilibili 官方）。整体是事件驱动的流水线：检测开播 → 下载录制 → 后处理 → 上传。

### 入口与启动
- `__main__.py`：argparse 解析参数（-P 端口、--no-http、--password 等），加载 config 与 DB，启动 `event_manager`，`main()` 里启动 web 服务或 AutoReload 守护。
- `__init__.py`：版本、日志配置(LOG_CONF)、Windows 事件循环补丁、PyInstaller IS_FROZEN 检测。
- `app.py`：创建 `EventManager` 与线程池(Asynchronous1/2)，`PluginInfo`(被 @event_manager.server() 装饰) 管理所有主播 URL 的检测协程；`shot()` 轮询各 URL 是否开播。

### 配置
- `config.py`：Config(UserDict)。支持 yaml/toml/config.json，DB 读写(load_from_db/save_to_db)，旧版 dump()。

### 引擎 engine/
- `event.py`：EventManager(线程) 事件队列 + 处理器注册；`register(type_, block)` 装饰器把函数挂到事件；`server()` 装饰器实例化类并绑定其方法为事件处理。`Event` 数据类。
- `decorators.py`：`Plugin` 类，用 `Plugin.download(regexp)` / `Plugin.upload(platform)` 装饰器收集所有插件到 `download_plugins`/`upload_plugins` 列表；`sorted_checker` 按 URL 正则匹配插件。
- `download.py`：`DownloadBase(ABC)` 所有下载插件基类。核心：`acheck_stream`(检测开播，由各平台实现)、`download()`(根据全局 downloader 选 stream-gears/ffmpeg/streamlink/sync-downloader)、`start()`(写 DB、跑弹幕、循环重试下载直到下播)、分段回调 `__download_segment_callback`(存文件名到 DB、跑 segment_processor)、封面下载、WBI 无关。含 `stream_gears_download`/`sync_download`/`get_valid_filename`/`get_duration`/`BatchCheck`。
- `upload.py`：`UploadBase` 所有上传插件基类。`file_list()` 扫描当前目录视频+对应 xml 弹幕，`get_max_upload_count` 控制重试上限，`start()` 加锁扫描文件并调 `upload()`(各平台实现)。`remove_filelist` 后处理删文件。
- `sync_downloader.py`：`SyncDownloader` 边录边传切片器（ffmpeg/streamlink 拉流 → video_queue → 上传线程消费）。

### 流水线处理器 handler.py
事件链：PRE_DOWNLOAD → DOWNLOAD → DOWNLOADED → UPLOAD → UPLOADED。
- `pre_processor`：触发 preprocessor。
- `process`：调 `biliup_download` 实际下载。
- `processed`：触发 downloaded_processor。
- `process_upload`：调 `uploader.upload`，含延迟检测、上传计数锁、webhook、max_upload_limit。
- `uploaded`：后处理(rm/mv/run)，默认删除文件。

### 下载/上传分发
- `downloader.py`：`download()` 按 URL 正则选 download 插件，general 兜底；`biliup_download` 是入口。
- `uploader.py`：`upload()` 按 config 的 uploader 选上传插件并反射构造参数，`fmt_title_and_desc` 格式化标题/简介（支持 {title}/{streamer}/{url} 与时间格式）。

### 数据库 database/
- `models.py`：SQLAlchemy ORM。StreamerInfo / FileList(1:N) / Configuration(key-value 整存配置) / UploadStreamers(投稿模板) / LiveStreamers(每个直播间配置，FK→UploadStreamers)。BaseModel.as_dict/filter_parameters 工具方法。
- `db.py`：SessionLocal；get/add/update/delete StreamerInfo、FileList；`migrate_via_alembic` 自动迁移。

### 公共 common/
- `log.py`：SafeRotatingFileHandler（修复重命名冲突）+ DebugLevelFilter。
- `Daemon.py`：fork 双次模拟 Linux 守护进程。
- `reload.py`：`AutoReload(Timer)` 检测源码变更+进程空闲时重启进程（支持 Docker 判断）。
- `timer.py`：`Timer` 线程定时执行（async 版 astart/arun）。
- `tools.py`：`NamedLock`(命名锁)、`get_file_create_timestamp`(跨平台创建时间)、`processor`(执行后处理命令)。
- `util.py`：全局 httpx AsyncClient(client/loop)、`check_timerange`(录制时间窗)。
- `tars/`：腾讯 TARS RPC 框架实现（疑似用于某些上传后端）。

### Web 服务 web/
- `__init__.py`：aiohttp 应用，`/v1/*` REST API（streamers 增删改查、upload streamers 模板、configuration、users、qrcode 登录、/ws/logs WebSocket 实时日志、/v1/uploads 手动上传、/bili/proxy 代理）。含 basic_auth 中间件与文件类型校验中间件。前端静态文件从 `biliup.web.public` 提供。
- `http_basic_auth.py` / `aiohttp_basicauth_middleware.py`：HTTP Basic Auth 实现。

### 弹幕 Danmaku/
- `__init__.py`：`DanmakuClient` 连接各平台 WebSocket 抓取弹幕，写成 B站兼容的 XML（`<d p=...>`/`<o>`/`<s>`）。按 URL 域名分派到具体平台实现。
- 平台文件：bilibili/douyin/douyu/huya/twitch/twitcasting/youtube（实现 get_ws_info/decode_msg/heartbeat）。douyin_util 含 protobuf 签名。

### 插件 plugins/（按平台）
- 下载插件（继承 DownloadBase，@Plugin.download 注册）：bilibili、douyin、douyu、huya、twitch、youtube、acfun、kuaishou、cc、bigo、afreecaTV、inke、kilakila、missevan、nico、twitcasting、flextv、yy + general(兜底 ykdl/yt_dlp/streamlink)。
- 上传插件（继承 UploadBase，@Plugin.upload 注册）：bili_webup(网页端)、bili_webup_sync(同步边录边传)、bili_chromeup(Chrome 扩展)、biliuprs(Go 后端 biliup-rs)、douyin、youtube、kuaishou 等 + noop_uploader(空操作，仅后处理)。
- `stream_gears.py`：stream_gears 库封装。
